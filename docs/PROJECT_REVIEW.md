## 本轮改变

- 建立 `references/yijing/decision-method.json`，以原典要点形成九步连续方法：辨位、观势、察几、审时、谋始、守正、虑患、变通、复盘。
- 页面保留《史记》《资治通鉴》说明和历史案例库；易经区同时展示原有六条精要、九步决策流程、三个案例应用。新流程没有替代已有内容。
- 实时推演按九个固定原则逐步提交现实判断、事实/未知和可执行动作；源码按原则 ID 补回原文和出处。
- 更新 Skill、架构、质量和业务文档；将本项目现代综合与古典原文分层，明示不是古代固定程序。
- 将本机订阅调用从 Claude CLI 迁移到 Codex CLI，加入只读沙箱、独立临时目录、Schema 输出及明确的健康检查；保留用户主动提供 Anthropic Key 的独立兼容选项。
- 依照项目既有暖纸色史书视觉优化页面，保持三源、所有示范与完整案例默认展示；移动端导航改为可横向浏览，不再隐藏主要入口。
- 修复本机接口拒绝跨来源 POST 时，未读取上限内请求体导致连接重置的问题；现在稳定返回 403。
