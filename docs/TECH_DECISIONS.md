# 技术决策记录

## Python 脚本

**用途：** 案例检索、字段和引文校验、语料下载、静态站点生成及可选本地服务。  
**选择原因：** 从仓库可确认使用 Python 3.10+，多数维护脚本只依赖标准库；原始选型原因待补充。  
**替代方案：** Node.js 或其他脚本语言；为何未选待补充。  
**注意事项：** 下载和繁简转换需要 `opencc-python-reimplemented`；完整引文核验还需取得 `corpus/`。

## 静态 HTML、CSS 与浏览器 JavaScript

**用途：** 提供 GitHub Pages 展示页和浏览器端交互。  
**选择原因：** 可直接作为静态页面部署；仓库没有前端打包器或服务端产品 API。维护者选择此方案的原始原因待补充。  
**替代方案：** 前端框架与服务端应用；是否评估过待补充。  
**注意事项：** 自带 Key 由浏览器调用 Anthropic；避免将密钥写入 HTML、源码或日志。

## Claude CLI 本机服务

**用途：** 可选地从本地网页调用用户已登录的 Claude Code 订阅。  
**选择原因：** 代码表明服务运行在本机并调用 `claude` CLI；为何采用此模式而非统一后端待补充。  
**替代方案：** 用户自带 API Key 模式（仓库已实现）。  
**注意事项：** 保持回环地址绑定、来源校验、无工具调用和安全模式参数。

## Anthropic SDK（浏览器按需加载）

**用途：** 在 BYOK 模式中调用 Anthropic API，SDK URL 锁定版本 `0.128.0`。  
**选择原因：** 代码表明使用官方 SDK；版本选择理由待补充。  
**替代方案：** 服务端代理或直接 HTTP 请求；未发现取舍说明。  
**注意事项：** 浏览器调用意味着 Key 会暴露于当前页面运行环境；只让用户自行输入并在浏览器保存。

## 维基文库及 OpenCC

**用途：** `fetch_corpus.py` 从维基文库取得《史记》《资治通鉴》文本并转为简体，供逐字核验与全文搜索。  
**选择原因：** 仓库文档说明文本来源和 CC BY-SA 录入本许可；选择该来源及 OpenCC 的原始原因待补充。  
**替代方案：** 其他公开校勘文本或转换工具；待补充。  
**注意事项：** 语料按许可不随仓库分发；完整引文核验依赖下载成功。

## 易经方法目录（结构化 JSON）

**用途：** 维护原句、篇章、原典链接、现代应用、反思问题、适用边界和示范案例映射。  
**选择原因：** 同一来源需要驱动网页方法卡、静态示范及实时推演；单一数据源减少页面文案、模型引用和说明文档之间的漂移。  
**边界：** 模型只返回目录 ID 和现代应用，客户端补入经过整理的固定引句；构建器做结构检查，不自动证明原典校勘无误。此功能采用非占卜式阅读。
