史鉴推演

纠结一个决定的时候，把你的处境说给它听。

它会用《史记》《资治通鉴》的正反先例分析人物选择与局势变化，再用《易经》的决策思想逐步检查变化、时机和行动，最后给你一条带前提与止损线的建议。

三种来源各有分工：史书提供证据，易经提供复核方法；历史给的是变量，不是答案。

史记与资治通鉴

这套系统以《史记》和《资治通鉴》的历史人物与事件作为推演案例库：先交代史料原文与出处，再比较人物所处位置、关键选择、结果和局限，帮助今天的决策者识别变量。历史案例是参照材料，不是现实人生的答案。

《史记》

以人物列传、本纪、世家等篇章呈现人物经历、选择与时代局势。本项目选取案例时保留篇名/卷次、关键原文、史料等级和现代映射，方便读者回到来源语境核对。

案例库覆盖择主、进退、合伙、用人、交班等现实决策母题；现代建议会标明与历史处境相似和不同之处。

《资治通鉴》

以编年脉络呈现事件前因后果和各方行动。本项目借此检查决策发生的时序、权力关系和连锁后果，避免把单个人物的成败抽离局势来读。

使用时区分可核对的行动与史家叙述、评论，并结合案例中的史料等级说明证据边界。

全部案例默认展开出处、原文、决定变量和迁移边界；也可按处境、史料等级筛选定位。

三源如何共同参与决策

每次实时推演都把现实处境、史书案例和易经方法放在同一条分析链里。史书提供可核对的行动与后果，易经提供逐步检查变化与行动的办法；系统综合证据后给出带前提和止损线的建议。

《史记》｜看人物与选择

从本纪、世家、列传中的人物处境、动机、关系与关键选择，比较正例和反例。案例保留篇章出处、原文、史料等级和现实迁移边界。

在推演中：回答“当事人是谁、手里有什么、为什么这样选、付出了什么代价”。

《资治通鉴》｜看时序与局势

按编年记录检查事件先后、各方行动和局势变化，避免把结果脱离当时条件，也区分可核对事件与史家判断。

在推演中：回答“局势怎样演变、什么信号出现后选择需要调整”。

《易经》｜看变化与行动方法

取经传中辨位、观势、察几、审时、谋始、守正、虑患、变通、复盘等思想，组织成九步现代决策复核流程。

在推演中：逐步核实事实与未知，转成可执行动作；不占筮、不预测，也不把现代流程说成古书原有程序。

现实处境与选项→两书正反案例与史料等级→易经九步检查变化与行动→建议、前提、止损线

三者分工不同：史书是历史证据，易经是现代反思方法。只有案例实际覆盖某部史书时，推演才会把它作为该次判断的直接历史依据；不拿空缺材料冒充证据。

怎么用

有三种用法：直接在这个页面填自己的 API Key；在本机打开页面，用你自己的 Claude 订阅额度；或者装成 Claude Code 技能，在 Claude Code 里说出你纠结的事，比如"帮我推演一下要不要辞职创业"。后两种都从下面这一行开始，装完就能用。

终端 · 一行安装
git clone --depth 1 __REPO__.git ~/.claude/skills/shijian-tuiyan

在 Windows 的 PowerShell 里，把 ~ 换成 $HOME。用 Codex 等其他 AI 工具的，克隆到任意目录，仓库根目录的 AGENTS.md 会告诉它怎么用。

想在两书全文里检索，或者改了案例要重跑引文校验，再下载原文语料。这一步可选，一两分钟：

终端 · 可选
cd ~/.claude/skills/shijian-tuiyan
pip install -r requirements.txt
python scripts/fetch_corpus.py
# 校验全部引文，应输出 FAIL 0 条
python scripts/verify_quotes.py

想在本机用订阅额度推演：先在终端登录一次 Claude Code，再启动本地页面。页面只在你的电脑上打开，对话框会通过本机的 claude 命令推演。

终端
# 只需一次：登录 Claude Code（用你的 Claude 订阅）
claude auth login
# 在后台启动本地页面，浏览器会自动打开 http://127.0.0.1:8765/
python scripts/serve_local.py --background
# 用完停止
python scripts/serve_local.py --stop

Windows 上不用敲命令：双击仓库里的 启动本地推演.bat，服务在后台运行，不占窗口；用完双击 停止本地推演.bat。
