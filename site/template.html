史鉴推演

纠结一个决定的时候，把你的处境说给它听。

它会从《史记》《资治通鉴》里找出走过同样局面的人，走对的和走错的都找，逐个推演每个选项的去向，最后给你一条带止损线的建议。

看一次完整推演 浏览历史案例

一个开源的 Claude Code 技能。历史给的是变量，不是答案。

你的处境鉴史书里的局

    一次完整的推演

    三个常见的抉择，每个都按同样的六步走完。点开案例名，可以看到它在史书里的原貌。

    个历史案例

    按你正在经历的处境找。每个案例都写了它在什么条件下成立，也写了什么条件下不成立。

    为什么可信

    人生建议最怕两件事：拿编出来的典故讲道理，和只挑对自己有利的故事讲。下面是这两件事的防线。

    怎么用

    它是一个 Claude Code 技能。装好之后，在 Claude Code 里说出你在纠结的事，比如"帮我推演一下要不要辞职创业"，它会自动开始推演。

    终端
    # 安装到 Claude Code 的技能目录
git clone __REPO__.git ~/.claude/skills/shijian-tuiyan
cd ~/.claude/skills/shijian-tuiyan
pip install -r requirements.txt
# 下载《史记》《资治通鉴》原文，一两分钟
python scripts/fetch_corpus.py
# 校验全部引文，应输出 FAIL 0 条
python scripts/verify_quotes.py

    源码、案例库和校验脚本都在 GitHub。

    需求、验收标准和真实场景试用：曹嘉鹏。实现借助 Claude Code 完成。

    推演结果是决策参考，不构成法律、财务、医疗或心理方面的专业意见。
