三源决策法

每次实时推演都把现实处境、史书案例和易经方法放在同一条分析链里。史书提供可核对的行动与后果，易经提供逐步检查变化与行动的办法；系统综合证据后给出带前提和止损线的建议。

《史记》｜看人物与选择

从本纪、世家、列传中的人物处境、动机、关系与关键选择，比较正例和反例。案例保留篇章出处、原文、史料等级和现实迁移边界。

在推演中：回答“当事人是谁、手里有什么、为什么这样选、付出了什么代价”。

《资治通鉴》｜看时序与局势

按编年记录检查事件先后、各方行动和局势变化，避免把结果脱离当时条件，也区分可核对事件与史家判断。

在推演中：回答“局势怎样演变、什么信号出现后选择需要调整”。

《易经》｜看变化与行动方法

取经传中辨位、观势、察几、审时、谋始、守正、虑患、变通、复盘等思想，组织成九步现代决策复核流程。

在推演中：逐步核实事实与未知，转成可执行动作；不占筮、不预测，也不把现代流程说成古书原有程序。

现实处境与选项→两书正反案例与史料等级→易经九步检查变化与行动→建议、前提、止损线

三者分工不同：史书是历史证据，易经是现代反思方法。只有案例实际覆盖某部史书时，推演才会把它作为该次判断的直接历史依据；不拿空缺材料冒充证据。

史鉴方法论

以人物抉择和时代局势两条史料路径检视现实问题：先辨人物、关系与得失，再还原事件时序、局势变化和连锁后果。

《史记》｜人物与抉择

从本纪、世家、列传中梳理人物处境、动机、关系与关键选择；对照正反先例，并标明来源、史料等级与现实迁移边界。

核心问题：谁在行动？掌握什么？选择带来哪些得失？

《资治通鉴》｜时序与局势

沿编年脉络复原事件前后、各方行动和局势变化，避免脱离条件只看成败；区分史实记录与史家判断。

核心问题：形势如何演变？哪些信号出现后应当调整？

怎么用

可以看示范、使用自己的 Anthropic API Key，也可以在本机通过 Codex CLI 推演；还可以把本项目安装成 Codex skill，在 Codex 里直接说出你纠结的事。

终端 · 一行安装
git clone --depth 1 __REPO__.git ~/.codex/skills/shijian-tuiyan

Windows PowerShell 可把 ~ 换成 $HOME。安装后重启 Codex，让它发现 SKILL.md。也可以克隆到任意目录，仓库根目录的 AGENTS.md 会说明项目约定。

想在两书全文里检索，或者改了案例要重跑引文校验，再下载原文语料。这一步可选，一两分钟：

终端 · 可选
cd ~/.codex/skills/shijian-tuiyan
pip install -r requirements.txt
python scripts/fetch_corpus.py
# 校验全部引文，应输出 FAIL 0 条
python scripts/verify_quotes.py

想通过 Codex 账户实时推演：先在终端登录 Codex CLI，再启动本地页面。服务只监听本机，对话框通过 codex exec 生成结构化结果。

终端
# 只需一次：登录 Codex CLI
codex login
# 在后台启动本地页面，浏览器会自动打开 http://127.0.0.1:8765/
python scripts/serve_local.py --background
# 用完停止
python scripts/serve_local.py --stop

Windows 上不用敲命令：双击仓库里的 启动本地推演.bat，服务在后台运行，不占窗口；用完双击 停止本地推演.bat。
