# 易经决策方法：来源、转译与使用边界

## 方法定位

这里保留原有六条《周易》决策思想精要，并在此基础上把经传中辨位、观察处境、变化、进退、忧虞和补过的思想整合为一套连续的现代决策工作流。精要用于呈现思想原文与原有案例；工作流将相关思想组织为操作步骤。它们互相补充；不占筮、不预测结果，也不代替用户负责。

六条精要与九步工作流均在 [`decision-method.json`](decision-method.json) 中维护，网页、案例报告和实时推演复用相同来源。工作流九个环节：辨位、观势、察几、审时、谋始、守正、虑患、变通、复盘。顺序是本项目为实际决策设计的工具结构，不是古代经典规定的操作程序。

## 原典来源

原文链接指向维基文库所收录的《周易》或唐孔颖达等《周易正义》文本，便于逐句核查；维基文库是在线转录入口，不等同于本项目已完成多版本校勘。经传作者、年代、形成过程有学术讨论。国家图书馆专题读物说明传统作者观与现代形成史研究，不能代替专业研究或校勘本。

## 版本与校验

生成器检查原则 ID、步骤完整性、字段及 HTTPS 来源；模型输出只能按固定 ID 填写分析，系统按目录补入经典原句和出处。这可防止来源自由生成，但不代表学术校勘。完整案例引文校验需另行准备项目史鉴语料，见 `scripts/verify_quotes.py`。

国家图书馆：《周易》专题导读（[PDF](https://www.nlc.cn/upload/attachments/2023-12-01/0932c8ff.pdf)），用于说明经传成书及作者观点的复杂性。引用该文不代表其为易学研究的唯一结论。
